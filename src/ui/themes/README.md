# 主题目录与多站点隔离规范说明

本目录 (`src/ui/themes/`) 下存放所有站点的主题实现。

## 核心架构原则

1. **完全孤立自包含**：每一个主题文件夹（如 `default/`, `turmill/` 等）都是一个完整的表现层宇宙，与其他主题完全互不干涉。
2. **禁止向公共代理层倒灌文案**：根目录下的 `Active*.astro` 属于所有主题共用的透明分发中枢。任何涉及具体品牌、特定套餐价格、专属行业业务的文案，**一律只准写在当前主题自身目录下**。
3. **单一独立页面通配契约**：所有单页（隐私政策、服务条款、注册协议等）均通过 `/[locale]/[slug]` 通配，主题只需要实现 `pages/SimpleDetailPage.astro`（或对应单页模板）即可自适应承接，严禁在 `src/pages/` 下手动为每个单页创建物理目录。
4. **CSS 作用域隔离**：每个主题的样式必须使用 `[data-theme='{themeId}']` 前缀包裹。
5. **单主题交付包验证**：每个主题必须保证能通过 `npm run pack -- {themeId}` 独立裁剪打包。

详细开发规范请参阅：[docs/THEME_ARCHITECTURE_SPEC.md](../../../docs/THEME_ARCHITECTURE_SPEC.md)。
