## 1. 买家痛点（首页与方案页共用）

### 痛点 1：有产品，没有「能接单的网站」
- 现象：依赖阿里/展会；独立站要么没有，要么像宣传册，搜不到、转化弱。
- 后果：询盘不可控，渠道一变业绩就抖。
- 我们的解法：磁帧鱼展示站（Astro）按 B2B SEO/GEO 结构输出；后台（Payload）随时改产品与内容，站点自动更新。

### 痛点 2：技术门槛吃掉业务时间
- 现象：Cloudflare、域名、Workers、Pages、缓存……学不完，也雇不起专职运维。
- 后果：项目卡在「半成品」，或长期被代理商绑架。
- 我们的解法：磁帧鱼部署桌面端一键交付 CMS + 站点，省去理解 Cloudflare 的成本。

### 痛点 3：询盘进来没人跟、跟了丢线索
- 现象：邮件/WhatsApp 散落；夜间接询盘无人回；新人答不上技术参数。
- 后果：热线索变冷，成交被截胡。
- 我们的解法：在线 CRM + 知识库 AI 客服，7×24 应答、线索留存、可人工接管。

### 痛点 4：SEO/GEO、社媒「知道重要，坚持不了」
- 现象：内容断更、关键词乱投、多平台发帖靠加班。
- 后果：流量贵、排名不稳，生成式搜索（GEO）完全没布局。
- 我们的解法：本地 Agent 内置成熟一键 SEO/GEO 与社媒方案，成熟流程几乎不怎么耗 Token，点点鼠标日常运营。

### 痛点 5：工具一堆，数据不打通
- 现象：建站一套、客服一套、发帖一套，重复录入。
- 后果：人效低，错漏多。
- 我们的解法：同一套外贸增长流水线——内容在 CMS，展示在站点，询盘进 CRM，运营由 Agent 驱动。

## 8. FAQ

1. **一定要买全套吗？**  
   不必。可按阶段上线：先站与后台，再询盘与自动化运营。提交需求后我们按现状给组合建议。  
2. **会不会绑定你们的服务器？**  
   部署目标是您自己的 Cloudflare 账户，资产与账号归您。  
3. **不懂技术能用吗？**  
   部署向导与日常改内容面向业务人员设计；复杂定制可再评估。  
4. **支持多语言吗？**  
   展示站与后台按多语言 B2B 场景设计，可按目标市场开启。  
5. **AI 客服会胡乱承诺价格或交期吗？**  
   应答基于您维护的知识库；关键承诺可配置转人工。  
6. **Agent 会不会产生很高的 Token 费用？**  
   方案强调成熟流程与一键动作，目标是少试错、低消耗地完成日常运营。  
7. **价格在哪里看？**  
   因模块组合与行业差异，价格不在官网公示。请提交询盘或预约演示获取方案与报价。  
8. **多久能上线第一版站点？**  
   视域名与内容准备情况而定；部署流程已产品化，演示时可按您的现状估算。
